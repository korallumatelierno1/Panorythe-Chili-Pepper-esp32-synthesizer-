What if building your own synthesizer was as simple as connecting a few touch electrodes and starting to code?

Chili Pepper is an ESP32-S3 development board designed specifically for building electronic instruments, synthesizers, and touch controllers.

Touch, sound, and open-source code
The Chili Pepper code is open source, so you can use it, modify it, and turn it into your own instrument.

You can pair the board with Panorythe, our ammonite-shaped touch controller, or create your own interface using almost any conductive electrode: copper pads, metal objects, custom PCBs, or completely experimental shapes.

Connect your electrodes, upload the code, and start playing.

How to upload code on Chili Pepper
Board name on Arduino : ESP32S3 Dev Module

Upload profile (midi enabled) :

->tools 

PSRAM : OPI PSRAM 

USB mode : USB-OTG (tiny usb)

Play these sequence with buttons if not recognized (usb direct ) : Hold boot, clic reset, release reset, release boot
